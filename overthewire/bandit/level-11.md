# Bandit Level 10-11

## Objective
-Find a password in an encoded data file

## Approach
-use man on base64
-use -d to decode

## Commands / Tools

```bash
man base64
base64 -d data.txt
```
Reasoning 
- -d decodes data in a file using base64

Result - Resolved level 11 password

What I learned
- How to decode base64 encoded data
