# Bandit Level 04 - 05

## Objective
-Find a password in a hidden file

## Approach
-Used find to see all files in the directory
-Opened the hidden file using cat

## Commands / Tools

```bash
find inhere
cd inhere
cat ...Hiding-From-You
```
Reasoning 
- find gives you all files in a directory
- cd opens the directory
- cat opens the file

Result - Resolved level 4 password

What I learned
-How to find hidden files in bash
