# Bandit Level 02 - 03

## Objective
Open a file with spaces in it's name

## Approach
-Used ./ and \ between spaces

## Commands / Tools

```bash
cat ./--spaces\ in\ this\ filename--
```
Reasoning - the ./ and \ allow gaps within a file name

Result - Resolved level 3 credentials

What I learned
-How to open a filename with spaces using ./ and \ between spaces
